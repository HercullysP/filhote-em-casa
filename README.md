# filhote-em-casa

O site está em [https://filhoteemcasa.com.br](https://filhoteemcasa.com.br).

As páginas HTML publicadas no GitHub Pages (`https://hercullysp.github.io/filhote-em-casa/`) redirecionam na hora para o mesmo caminho nesse domínio, preservando a query string (UTMs, `fbclid`) e o hash. Os arquivos em `/ads/` e `/assets/` continuam servidos por este repositório.
